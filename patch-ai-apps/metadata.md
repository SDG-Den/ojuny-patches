# AI desktop apps

This patch adds opt-in hosted AI desktop applications and web-app presets. It
is off by default. Nothing is installed until `ojuny.patch.ai-apps.enable` is
true, and every individual app is off by default as well.

## What this patch installs

Native packages, all off by default:

- ChatGPT desktop (`pkgs.chatgpt`).
- T3 Code (`pkgs.t3code`).
- OpenClaw (`pkgs.openclaw`).
- LM Studio (`pkgs.lmstudio`).

Web-app presets, all off by default:

- Claude.
- Perplexity.
- Grok.
- Hermes.

Claude, Perplexity, Grok and Hermes have no desktop package in the pinned
nixpkgs, so they are Chromium web apps. Each row is a table entry; turn a row on
to install its desktop entry.

## Requirements

ChatGPT desktop is unfree. Set `nixpkgs.config.allowUnfree = true` or the
evaluation fails when the ChatGPT toggle is on. The Ojuny template already sets
it in `modules/02-core/11-nixsettings.nix`. A standalone user must set it in
their own configuration.

## Optional chromium-webapps input

The web-app half needs the `chromium-webapps` flake input:

```
chromium-webapps.url = "github:chobbledotcom/nix-chromium-webapps";
```

The patch imports its Home Manager module only when `inputs ? chromium-webapps`
is true. Without the input the native toggles still work and the web-app half
stays inert: no web apps are added and no evaluation error occurs.

The patch maps `ojuny.patch.ai-apps.webApps` to
`programs.chromium-webapps.webApps` and does not touch `ojuny.webapps`, which
belongs to the template-only webapps module.

## Hosted versus local

This patch is the hosted path only. `patch-local-llm` owns the local model
path: the model server, its `desktopClient` choices, Jan and Open WebUI. This
patch does not duplicate Jan or Open WebUI and does not install a model server.

## Removal

1. Turn every app and web-app row off, or turn the patch off.
2. Rebuild.
3. Run `ojuny-patches remove patch-ai-apps`.
4. Remove the `chromium-webapps` input if no other patch uses it.
